# Original Content Blueprint

状态：`Calibration v3` 已完成校准；按该规则写成的 `original-production-v1` 已包含完整 66+2、七套结果/Shadow、42 组 Pairing 和四类特殊结果，并通过三项独立 Agent 复验。用户本人完整内容审阅仍未进行。

## 1. 路线决定

本站保留用户寻找完整 Soul Virtues 测试时期待的产品结构，但不复制参考站的题目、权重矩阵、结果长文、Pairing 文案、特殊文案或品牌包装。

保留的产品契约：

- 66 道计分题 + 2 道原创特殊问题；
- 七个维度、五档回答、Primary、Secondary 和 Full Spread；
- Shadow、42 个有方向的 Primary -> Secondary Pairing、特殊结果和分享卡；
- 现有 payout、curve、排序、状态机、LocalStorage 和结果/分享共用模型；
- 移动优先、复古游戏氛围、非官方声明和参考来源 attribution。

必须原创的内容：

- 题目文字、题目顺序和完整权重矩阵；
- 两道特殊问题及其对话文字；
- 七套 Primary 解释和 Shadow；
- 42 组有方向的 Pairing；
- 四类完成型特殊结果的标题与解释；
- 所有分享短句和内容型 Easter Egg 表达。

本站不得宣称结果与参考测试相同，也不得把 Jaden 相关导航词放入品牌名或 H1。

## 2. 七维编辑定义

| 维度 | 本站定义 | 健康表达 | 失衡风险 | 与相邻维度的边界 |
|---|---|---|---|---|
| DET / Determination | 遇到阻碍后重新选择方向并继续行动的能动性 | 调整路径、重新开始、保留选择权 | 隧道视野、把转向当失败 | DET 是“再次选择并推进”；PER 是“长期维持投入” |
| BRV / Bravery | 在恐惧、风险或注目仍存在时采取必要行动 | 承认风险后行动、求助、保护重要事物 | 为证明勇敢而冒险 | BRV 处理恐惧与风险；DET 处理阻碍与方向 |
| JUS / Justice | 关注公平、责任、权力差异和可修复的后果 | 比例适当的问责、质疑不公平规则 | 过度审判、忽略情境 | JUS 面向外部公平；INT 面向内部言行一致 |
| KND / Kindness | 看见需要并提供尊重边界的实际照顾 | 同理、支持、诚实说明能力范围 | 自我抹除、替别人承担全部责任 | KND 决定如何关怀；PAT 决定何时等待 |
| PAT / Patience | 主动容纳不确定性并等待足够信息或合适时机 | 观察、延迟冲动、给成长留时间 | 拖延、用等待逃避选择 | PAT 是有目的的等待，不是被动不行动 |
| INT / Integrity | 在无人监督时仍让价值、陈述和行为保持可解释的一致 | 守信、承认错误、依据证据修正 | 僵化、把改变看成背叛 | INT 关注自己的标准；JUS 关注共同规则和结果 |
| PER / Perseverance | 在新鲜感消退和重复出现后仍能维持有意义的练习 | 稳定投入、改变方法、跨越小挫折 | 沉没成本、重复无效方法 | PER 是持续性；DET 是遭遇中断后的再启动 |

这些定义是娱乐性写作框架，不是心理测量构念，也不支持科学、医疗、雇佣或诊断结论。

## 3. 题目与权重规则

### 文字

- 使用第一人称、单一行为或选择，避免一题同时问两件互相独立的事；
- 使用普通生活情境，不考 Undertale 知识，不借角色选择暗示“正确答案”；
- 每个维度同时包含 direct 与 reverse 题，避免一直同意即可得到高分；
- 避免“always / never”、羞辱、临床标签、创伤细节和明显道德审判；
- 不复制或近义改写参考站题目；批量完成后必须单独做相似度与人工来源复核；
- 通用五档标签为 Strongly disagree / Disagree / Neutral / Agree / Strongly agree；只有语义方向清楚且五档仍保持同一连续轴时，才允许使用经过审阅的情境标签。

### 权重

- 校准样本使用主维度 `+3` 或 `-3`；只有文字本身对第二维度提供直接证据时，才允许添加绝对值为 2 的次权重；
- Calibration v3 的 14 题为 7 道单维和 7 道双维，保留 2 道情境回答标签，不再要求三维题或正负混合权重；
- 题型分布和归一化平衡不得凌驾于内容语义；无法同时满足时先删掉缺少依据的次权重，再调整其他真实题目；
- 0 表示该题不影响该维度，七维字段始终完整；
- reverse 题的主权重为负，不能只靠措辞反转；
- 完整 66 题中，每个维度的主目标题数量只能相差 1；每个维度至少 4 道 direct 和 4 道 reverse；
- 完整数据的各维 `normalisationMax` 目标差异不超过平均值的 10%；超出时先审题，不通过机械放大权重补齐；
- 先由编辑定义权重，再由第二次独立审查检查跨维关系；不得根据“想要的结果”反向篡改单个用户答案。

## 4. 结果文案规则

- Primary 摘要说明倾向和使用方式，不写成永久身份判决；
- Shadow 描述优势失衡后的风险，同时给出更成熟的表达，不制造羞耻；
- 每个 Primary 都提供一个 `confusedWith` 边界解释，用具体行为区分最容易混淆的相邻维度；
- Pairing 有方向：`DET -> PAT` 与 `PAT -> DET` 是不同文本；
- Pairing 必须分别说明 Primary 提供的驱动力、Secondary 提供的修正，以及两者的张力；
- 特殊结果描述回答模式，不推断用户故意捣乱、撒谎或具有某种人格；
- 所有结果继续声明娱乐用途，不使用 scientific、accurate diagnosis 等承诺。

## 5. Calibration v3 样本

机器可读样本位于 `src/data/original-content-calibration.ts`，包含：

- 每个维度 1 道 direct + 1 道 reverse，共 14 道原创题；
- 14 题由 7 道单维和 7 道双维构成，含 2 套情境回答标签；
- 每道双维题的次权重均有文字证据；七维绝对权重和均为 8；
- 7 个 80-110 词 Primary 摘要、60-90 词 Shadow，以及 7 个 50-80 词易混淆维度解释；
- `DET -> PAT`、`JUS -> KND`、`BRV -> INT` 三个有方向 Pairing；
- 三个 Pairing 均为 65-95 词，并包含 Primary 驱动力、Secondary 修正和两者张力；
- `all-neutral` 的一个原创特殊结果样本，游戏叙事与解释性免责声明分字段保存。

它显式标记为 `calibration-only` 和 `productionEligible: false`，不会作为当前页面的数据源。首页使用独立的 `src/data/original-production-dataset.ts`；校准样本继续保留为内容规则证据。

## 6. 样本验收问题

进入完整 66+2 写作前，需要针对 Calibration v3 逐项回答：

1. 七个维度是否足够容易区分，特别是 DET/PER、JUS/INT、KND/PAT？
2. reverse 题是否自然，而不是让人一眼看出“坏答案”？
3. 题目是否适合移动端快速阅读，并且没有依赖特定年龄、职业或关系状态？
4. Primary、Shadow 和 Pairing 是否像同一套产品语言，但没有模仿参考站的句子？
5. 特殊结果是否有游戏感，同时没有指责用户？

通过内容验收后，下一阶段才扩写完整 66+2，并建立正式 dataset、来源记录、Golden vectors 和浏览器验收。校准样本通过结构测试不等于内容已获真人验收。
